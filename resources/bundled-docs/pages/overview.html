VI History Suite

vi-history-suite is a governed Visual Studio Code extension for expert review of LabVIEW VI history in Git repositories.

This wiki is seeded from governed repository documentation, not from source code or prior chat state. The current authority surfaces for this page are:

  • docs/product/SHIP-0001-releasable-vi-history-suite.md
  • docs/product/current-state.md
  • README.md
  • docs/product/release-readiness-matrix.json

Product Promise

The current ship target is to release vi-history-suite as a versioned VSIX that a user can install and use to:

  • right-click an eligible LabVIEW VI in a trusted Git repository
  • review commit history for that VI
  • generate reliable NI comparison reports
  • review a metadata-concentrated dashboard across at least three commits
  • retain a separate human decision record without mutating machine evidence

What Exists Now

The extension currently provides:

  • content-detected VI eligibility and menu gating
  • review-oriented history panel actions
  • version-matched bundled user documentation that opens locally inside the installed extension
  • reliable governed NI comparison-report generation
  • a multi-report dashboard for one VI across at least three commits
  • dashboard progress and retained pair-level ETA characterization
  • runtime-doctor surfaces
  • separate decision-record creation from retained dashboard evidence
  • a docs-authoring workbench and repo-native docs gate for governed documentation iteration
  • a governed wiki-authoring system that stages page-authority bundles and publication-prep receipts before wiki widening
  • a commit-aligned published-image GitLab wiki-preparation lane that replays doctor, plan, and prepare from the repo-published docs-authoring image

Install Surfaces

Current install and release surfaces are:

  • preview VSIX artifact from the main pipeline
  • local package output via npm run package
  • governed tagged release artifact retained under release-evidence/
  • packaged bundled user docs opened through VI History: Open Documentation and the history-panel Open docs action
