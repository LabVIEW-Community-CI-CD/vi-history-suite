vi-history-suite

vi-history-suite is a Visual Studio Code extension for reviewing LabVIEW VI history in Git repositories.

Use the installed guide inside the extension for first-time setup, checkbox-selected compare workflow, retained comparison review, and execution-policy tasks without needing the broader engineering control plane.

Install Surfaces

Current install and release surfaces are:

  • VS Code Marketplace listing under svelderrainruiz.vi-history-suite
  • VSIX attached to a diagnostic prerelease when a maintainer publishes one for a specific investigation (exceptional path, not the normal release)
  • local package output via npm run package when you are testing from source
  • packaged bundled user docs opened through VI History: Open Documentation or the history-panel Open docs action

First-time flow:

  1. run VI History: Set Up Comparison Runtime
  2. run vihs
  3. choose provider, LabVIEW year, and bitness
  4. run vihs --validate
  5. open VI History on the tracked VI you want to review; the extension evaluates that selected file before compare
