Install Surfaces

Current install and packaging paths are:

  • preview VSIX artifact from the latest successful main pipeline
  • local package output via npm run package
  • future governed tagged release artifact under release-evidence/
  • packaged bundled user docs surfaced through VI History: Open Documentation and the history-panel Open docs action

The preview VSIX is the current install surface for extension-user testing. The tagged release artifact is the future governed exact-version install surface.

Release Procedure Summary

The current governed release flow is:

  1. keep main in a governed baseline state
  2. ensure package.json matches the vX.Y.Z tag exactly
  3. let GitLab CI run compile, tests, coverage, and VSIX packaging
  4. retain release evidence under release-evidence/
  5. review the release record and machine-readable manifest before downstream distribution
