Release Procedure Summary

The current governed release flow is:

  1. keep main in a governed baseline state
  2. ensure package.json matches the vX.Y.Z tag exactly
  3. let GitLab CI run compile, tests, coverage, and VSIX packaging
  4. retain release evidence under release-evidence/
  5. review the release record and machine-readable manifest before downstream distribution
