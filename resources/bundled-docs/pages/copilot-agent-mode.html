Copilot Agent Mode

VI History Suite ships a built-in Model Context Protocol (MCP) server that exposes its LabVIEW VI comparison, history, and repository analysis to AI agents. When the extension is installed, Copilot agent mode discovers the server automatically, so there is nothing to configure.

The agent-mode surface requires VS Code 1.101 or later; on older editors the extension skips the registration and every other feature keeps working.

What You Can Ask

Work with your VIs in plain language, for example:

  • Summarize what changed in a VI comparison report.
  • Compare the last two revisions of a specific VI and explain the change.
  • Walk a VI's recent history and describe how it evolved.
  • Index the LabVIEW VIs in the repository, ranked by recent activity.
  • Fetch or validate the published VI-diff schemas.

Available Tools

The server provides seven tools:

ToolWhat it doesRuntime
summarize_vi_comparisonConcise what-changed narrative for a comparison report.None
get_vi_semantic_comparisonFull semantic comparison model for a comparison report.None
compare_vi_revisionsRuns a LabVIEW comparison between two Git revisions.Comparison runtime
summarize_vi_historyWalks a VI's recent revisions and builds an evolution timeline.Comparison runtime
index_repository_visSurveys tracked VIs, activity-ranked, with revision counts.None (Git only)
get_vi_semantic_schemaReturns the published VI-diff JSON Schemas.None
validate_vi_semantic_documentValidates a self-describing document against its schema.None

Runtime Requirements

  • compare_vi_revisions and summarize_vi_history run a real LabVIEW comparison, so they need a comparison runtime (the same host LabVIEW or Docker image you selected for the interactive compare flow) and may take a few minutes.
  • The remaining tools use Git or supplied data only and return immediately.

Open VI-Diff Standard

The comparison, history, and repository-index results are published as versioned Draft-07 JSON Schemas so other tools can consume or validate them:

  • vi-history-suite/vi-semantic-comparison@v1
  • vi-history-suite/vi-semantic-history@v1
  • vi-history-suite/vi-repository-index@v1

Fetch a schema with get_vi_semantic_schema and validate any document that carries a schema field with validate_vi_semantic_document. The full tool reference is published in the project repository.
