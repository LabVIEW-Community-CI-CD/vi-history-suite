Vendored third-party LabVIEW VIDiff orchestration reference
===========================================================

Directory: vidiff/  (vidiff.sh, vidiff.ps1)
Purpose:   NI's reference "VIDiff" orchestration for headless VI comparison in
           containers/CI. It renders each side of a diff with the sibling custom
           LabVIEWCLI operation PrintToSingleFileHtml (vendored one level up at
           resources/labview-cli-operations/PrintToSingleFileHtml) and structurally
           diffs the rendered outputs. This is NI's supported headless-Linux VI-diff
           path precisely because the built-in LabVIEWCLI CreateComparisonReport
           operation does NOT run headless on Linux — it trips a recursive GSW
           (Getting Started Window) LEIF load (see
           docs/vhs-req-706-recursive-load-repro-brief.md, VHS-REQ-706).

Role:      REFERENCE ONLY. The VI History Suite does NOT invoke these scripts at
           runtime; they are the in-repo source-of-truth that the decoupled
           Linux render-diff producer (#2315) is modeled on (binary-file
           detection + added/deleted-VI handling per upstream #49). They live in a
           vidiff/ subdirectory, NOT loose in the labview-cli-operations root, so
           they are never scanned as a LabVIEWCLI -AdditionalOperationDirectory
           operation.
