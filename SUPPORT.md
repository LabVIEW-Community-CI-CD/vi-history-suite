# Support

Use GitHub Issues for bug reports, feature requests, and source-evaluation
problems:

https://github.com/LabVIEW-Community-CI-CD/vi-history-suite/issues

Before opening an issue, please check:

- [README.md](./README.md) for install and usage basics
- [INSTALL.md](./INSTALL.md) for first-run and source-evaluation steps
- [TROUBLESHOOTING.md](./TROUBLESHOOTING.md) for common problems

For source evaluation, the preferred path is a devcontainer or Codespace.
Vagrant is optional and only for humans who already have a compatible
Windows/LabVIEW box.

Do not use public issues for security vulnerabilities. See
[SECURITY.md](./SECURITY.md).
