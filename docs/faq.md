## Questions

### How do I start?

Start with `README.md` to choose the right route, then use `INSTALL.md` if you
are following the exact released installed path. If you are evaluating source
or branch truth instead of the released extension, stay on the repo routes and
do not treat released installed guidance as active `develop` doctrine.

### Where do I find the key commands or checks?

Use `docs/quick-reference.md` for the compact command and route surface. Use
the command reference under `docs/information-for-users/command-reference.md`
when you need the deeper maintainers' command split.

### What should I do when the expected route fails?

Return to `docs/user-guide.md` and re-check whether you are on the released
installed path, a source-evaluation path, or an active `develop` maintainer
path. If the repo route still fails, use `docs/quick-reference.md` for the
stable checks and `docs/release-procedure.md` when the failure is release- or
publication-facing.
